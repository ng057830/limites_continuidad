# Rafael · Laboratorio de Límites y Continuidad

Aplicativo interactivo para repasar límites y continuidad en 2º de Bachillerato.

## Uso

Abre `index.html` en cualquier navegador moderno. No necesita instalación ni servidor.

Incluye funciones continuas, discontinuidades removibles, saltos finitos, discontinuidades infinitas, picos y oscilaciones; aproximación por ambos lados; franjas delta-épsilon; animación y comprobación final.
